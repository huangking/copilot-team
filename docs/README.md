# 交接产物

本目录是四个 Agent 之间**唯一可信的交接面**。聊天记录不算数。

| 目录 | 产生者 | 内容 |
|---|---|---|
| `specs/` | PM | 目标、非目标、验收标准（`AC-*`）、任务拆分、风险 |
| `plans/` | Dev | 改动点、取舍、验证命令、风险 |
| `test-reports/` | Test | 用例矩阵、实际输出、失败复现、覆盖缺口 |
| `releases/` | DevOps | 发布步骤、回滚、观测项、结果 |

约定：

- 文件命名 `<四位编号>-<kebab-case>.md`，例如 `0001-export-csv.md`。
- 下游开始前必须读到上游文件，并在回复里引用路径。
- 上游文件为空或与代码不一致时，退回上游，不要自行补全需求。
