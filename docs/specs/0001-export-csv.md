# 0001：任务板 CSV 导出

- 状态：ready（等待实现）
- 负责：Dev → Test → DevOps
- 来源：用户需求 "我想把任务导出到表格里，给不做开发的人看"

## 背景与目标

任务目前只能通过 `taskboard list` 在终端查看。非开发同事需要把任务导入表格软件，
因此需要一条稳定的 CSV 导出通道。

## 非目标

- 不做 Excel（`.xlsx`）导出。
- 不做远程上传、分享链接、邮件发送。
- 不改变现有 `add` / `list` / `done` 的行为与存储格式。

## 验收标准

| ID | 标准 | 验证方式 |
|---|---|---|
| AC-1 | `taskboard export --format csv` 按 `id` 升序输出：首行 `id,title,done`，其后每任务一行，`done` 为 `true`/`false`；退出码 0 | `python3 -m pytest tests/test_export.py -q`（Test 新建） |
| AC-2 | 标题含逗号、双引号或换行时按 RFC 4180 加引号，内部双引号写成两个双引号 | 同上，参数化用例 |
| AC-3 | 空任务板只输出表头一行，末尾有换行 | 同上 |
| AC-4 | `--format` 只接受 `csv`；其他值向 stderr 报错并以退出码 2 结束，不输出半截 CSV | 同上 |

## 边界与错误场景

- 存储文件不存在：视为空任务板（沿用 `list` 的现有行为）。
- 存储文件损坏：沿用现有 `TaskError` 处理，退出码 2，stderr 带 `invalid store`。
- 标题包含 Unicode（中文、emoji）：原样输出，不做转义。
- 大文件：不做流式优化，本阶段任务量 < 10k。

## 任务拆分

| # | 任务 | 依赖 | 角色 |
|---|---|---|---|
| 1 | 领域层生成 CSV 行（含转义） | - | Dev |
| 2 | CLI 增加 `export --format csv` | 1 | Dev |
| 3 | 补测试：正常、转义、空板、非法格式 | 1,2 | Dev / Test |
| 4 | 独立验证并出报告 | 3 | Test |
| 5 | 发布记录（镜像无需改动） | 4 | DevOps |

## 风险与回滚

- 风险：标题里的换行会让"一行一任务"的假设失效 → 必须按 AC-2 加引号。
- 风险：误把 CSV 输出到 stderr 之外的日志里 → 测试需断言 stdout 精确内容。
- 回滚：纯新增子命令，无数据迁移；回滚只需回退提交。
